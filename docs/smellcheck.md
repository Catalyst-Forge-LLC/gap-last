# Smell Check overlay

House overlay on `smellcheck`. Core bans live in the package. This file
is only what is true here.

Do not restate the hard bans. Do not fork `core.md`. Do not de-smell
the maxim or verbatim testimony. Smell-check the tool's own output,
not the user's traces.

## Pronouns

- Landing / site pages: you, or no pronoun. No corporate we.
- README / CLI / Run: you.
- About: the product (Gap Last / it). No builder I.
- Essays / posts: the reconstruction voice (bound first). No we.
- Papers / spec: Sam's draft. Do not rewrite for colleague register.

## Protected lines

Smell Check already protects:

- Earn the word.
- Spray the prose, not the author.
- Have you smell-checked that?

This project also protects:

- Don't invent a cause until you can name the gap.
- Pursue the "how" at your folly if you fail to frame the correct "what".
- The prohibition is the product.
- A parent, a patient, a founder, and an agent meet the same shape: something arrived, you did not get to rerun it, and a story is already forming.
- The four-line deed (GENESIS §10.2), verbatim.
- The reconstruction is the format.

Do not rewrite the living spec or paper to pass a landing audit.
