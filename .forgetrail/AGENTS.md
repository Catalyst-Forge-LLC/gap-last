# Agent guardrails (Gap Last)

This file is for any coding agent that lands in this repo.

- Follow `GENESIS.md`. Method behavior follows `docs/gap-last-tool-spec.md`.
- Do not invent a cause until a residual gap is named.
- Do not publish to npm. `gaplast@0.0.0` is a name hold, not this tree.
- Do not create a GitHub remote unless Sam asks.
- Do not scaffold a FilePress site in the same sitting as M1 unless asked.
- Commit after substantive work. Use a plain message. Do not add
  unrequested attribution trailers (`Co-authored-by`, `Signed-off-by`,
  Generated-by, or `git commit --trailer`) unless the user asks.
- Project git rule (`.cursor/rules/git-user-commits.mdc`) also asks
  for `Co-authored-by: Cursor <cursoragent@cursor.com>` on this
  repo. Follow that only because this repo's rule is explicit.
- Do not push until a remote exists and Sam asks, or a local mirror
  is attached the way sister tools use `D:/git-mirrors/`.
