# Engineering decision: <job>

Use only the detail this decision needs. This is a Markdown aid, not a
CLI-valid reconstruction. Proposed, applied, and verified are different.

## Starting point and bound

Observed problem, declared goal, exploratory idea, or a labeled combination.
Who needs to do what? Constraints, scope, and revision when available.

## Evidence and unresolved question

Sources and actual observations. Implemented behavior versus intent.
What remains uncertain? Name the question the intervention must answer.

## Alternatives and distinguishing check

Plausible responses, including no change. What check distinguishes them?
What ran and what did it show? Name unavailable execution rather than
substituting a predicted result for an observation.

## Decision and verification

Smallest sufficient response, bounded experiment, or no change justified.
Acceptance criteria, dependencies, authorization state, and verification.
Applied and verified results only if they actually exist.

## Remainder and reopening

What is still unknown? What evidence would change this choice?
Link to existing authoritative records instead of copying their status.
